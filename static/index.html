Documentation

How ZeroWare checks a file and how to read the report.

How scanning works

  1. ZeroWare calculates a SHA-256 fingerprint on your device.
  2. The server checks that fingerprint with VirusTotal.
  3. If VirusTotal has no report, you can approve an upload for analysis.
  4. Results shows the engine verdicts returned by VirusTotal.

Privacy

Known files are checked by fingerprint only. VirusTotal may share uploaded files with security partners. Choose Cancel for personal, private, or confidential files.

Your latest report is held in this page for the current session.

Reading the results

Flagged
An engine reported the file as malicious or suspicious. Open “Learn more” to see what its label generally means.
Clean
The engine reported no detection. A clean report cannot guarantee a file is safe.
Not scanned
The engine did not return a usable verdict for this file.

Limits

Files can be up to 650 MB. Uploads and analysis can take several minutes. If VirusTotal reports a rate limit, wait and retry.

The web scanner reports results from VirusTotal. Device scanning and quarantine are features of the desktop app.
