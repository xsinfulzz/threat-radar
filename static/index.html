ZeroWare Documentation

Overview

ZeroWare is a web-based file scanner. Drop in a file and ZeroWare checks it against more than 70 antivirus engines through the VirusTotal API, then shows a clear green or red verdict with a per-engine breakdown.

ZeroWare is a front end and relay for VirusTotal. It does not run its own antivirus engine, and it is not affiliated with VirusTotal.

How it works

Every scan follows the same four steps:

  1. 1. You choose a fileZeroWare gives your file a unique ID tag, a bit like a name tag that identifies it (this is the "fingerprint" you see on screen). This happens on your own device, so your file isn't sent anywhere yet.
  2. 2. ZeroWare serverReceives the ID tag and sends the scan request to the VirusTotal API using a private API key stored on the server.
  3. 3. VirusTotal APIMore than 70 antivirus engines review the file and each returns its own verdict.
  4. 4. Results back to ZeroWareThe server tidies VirusTotal's response and sends it to your page, which draws the verdict, engine grid and threat list.

If VirusTotal has never seen the file, ZeroWare asks your permission before uploading it, then waits for the engines to finish and shows the results.

Reading the results

ResultMeaning
Green: No threats detectedNo engine flagged the file. This is reassuring but not a guarantee of safety.
Red: FlaggedOne or two engines flagged it. A single detection is often a false positive, so check the source of the file.
Red: MaliciousThree or more engines flagged it. Do not open the file.

The engine list uses these labels: malicious and suspicious count as threats, harmless and undetected count as clean, and anything else shows as "Not scanned" (for example, an engine that does not support that file type).

Next to every flag there is a Learn more button. It explains in plain words why that engine flagged the file and what it could mean.

Privacy

  • Files that are already known are checked using just their ID tag. The file itself is never uploaded.
  • Unknown files are uploaded only after you click Upload and scan. VirusTotal may share uploaded files with security companies, so never upload private or personal files.
  • The VirusTotal API key stays on the ZeroWare server and is never sent to your browser.
  • ZeroWare does not keep your files or scan history.

Limits

  • Maximum file size is 650 MB. Files over 32 MB use VirusTotal's large-file upload and can take several minutes.
  • A free VirusTotal API key is rate limited (about 4 requests per minute), so many users at once may see a "rate limit" message. Wait a minute and try again.
  • ZeroWare reports what the engines say. It cannot remove viruses, and a clean result does not prove a file is safe.
  • Brand-new malware may not be recognised yet.

FAQ

Why did only one engine flag my file?
With 70+ engines, a lone detection is usually a false positive, especially on small tools, games or custom software.

What does "not scanned" mean?
That engine did not return a verdict, often because it does not support the file type or timed out.
